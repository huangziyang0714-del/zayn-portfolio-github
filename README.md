# ZAYN Portfolio

React 19 + Vite 7 personal portfolio for Zayn Huang.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

The deployable source is this folder. `public/assets` contains the portfolio media and embedded project sites. `dist` is generated output and is intentionally ignored by Git.
