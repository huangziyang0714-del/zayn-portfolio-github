## Layout rules

- Each poster is designed to the exact desktop card ratio, with a protected inner logo area.
- The card background and the logo are separate HTML layers so logos remain visible in real browsers and can be replaced independently.
- Mobile keeps the first three poster ratios instead of forcing a common crop.
